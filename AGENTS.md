- The user performs all Unity Editor actions manually. Provide clear, step-by-step instructions for those actions.
- Codex may create and edit scripts. Do not automate Unity Editor actions or directly edit scenes, prefabs, or other Unity assets to perform Editor setup.

- Instruct the user how to create or select GameObjects, configure components, assign Inspector references, and change project settings in the Unity Editor.
